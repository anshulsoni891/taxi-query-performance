Query Optimization & EXPLAIN ANALYZE Deep-Dive

Q1: Monthly Revenue Aggregation 12.11x Faster

Fix: BTREE index on tpep_pickup_datetime eliminates full table scan.

SELECT DATE_TRUNC('month', tpep_pickup_datetime), SUM(total_amount)
FROM trips WHERE tpep_pickup_datetime >= '2023-01-01'
GROUP BY 1;
Q2: Avg Tip % by Borough Join 9.44x Faster

Fix: Foreign key indexes on pu_location_id and do_location_id.

SELECT pu_loc.borough, do_loc.borough, AVG(t.tip_amount)
FROM trips t JOIN locations pu_loc ON t.pu_location_id = pu_loc.location_id ...
Q3: High Volume Zone Aggregation 12.42x Faster

Fix: Composite index on (pu_location_id, fare_amount) for index aggregation scan.

SELECT pu_location_id, COUNT(*), AVG(fare_amount)
FROM trips GROUP BY 1 HAVING COUNT(*) > 10000;
Q5: Anomaly Trip Filtering 26.60x Faster

Fix: Composite index on (passenger_count, trip_distance, tip_amount).

SELECT * FROM trips WHERE passenger_count >= 5
AND trip_distance > 15.0 AND tip_amount < 1.0;
